# Projects and Areas of Exploration

## Practical Project Experience

### University Library Management System

I personally built a library management system for a reputed university. The system is currently in beta testing, and I hope the university will implement it.

This is one of my most successful projects because it moved beyond an isolated exercise toward possible use by a real institution. It represents the kind of work I value: understanding a real need, building a usable system, and improving it through feedback.

### Clothing Buy-and-Sell Platform Deployment

An IT company needed a buying-and-selling platform for a clothing brand. I took an existing open-source solution, adapted and implemented it for their needs, and deployed it on their server.

This should not be described as a system built entirely from scratch. Its value was in understanding an existing project sufficiently to configure, adapt, and deploy it in a real environment.

## How I Want to Build

A successful project does not need a huge audience. A tool built for myself that later helps four or five people is already worthwhile.

I want to:

- understand the problem before choosing technology;
- write and understand my own code;
- encounter and repair real errors;
- know why each important component exists;
- deploy projects rather than leave everything as local demonstrations; and
- create useful work that can remain free when appropriate.

I am currently using AI assistants as learning collaborators while expanding into new projects and technologies. The assistant should support understanding, not quietly replace my work.

## Areas I Want to Explore

### Cybersecurity

Early exposure to keylogging behavior, password brute-forcing, predictable URL structures, and public-resource discovery sparked my curiosity about cybersecurity.

I want to build the foundations needed to study web and application security, authentication, access control, network security, defensive practices, and responsible security testing. This is a long-term learning direction, not a claim of professional security experience.

### Artificial intelligence and machine learning

I am interested in AI and machine learning, particularly where they support academic work, research, or useful projects. I am still determining whether this will become a central field or remain one part of a broader technical path.

### Computer vision and image processing

I want to learn Python, mathematics, and the necessary foundations for computer vision and image processing. These are future learning directions rather than current expertise.

### Hardware and Raspberry Pi

Hardware is currently a weak area, but I am not afraid of it. I want to approach Raspberry Pi and hardware projects gradually with proper guidance, safety, and explanations.

### Mathematics

My mathematical foundation is currently weak. I want to improve it because mathematics supports algorithms, AI, research, computer vision, cybersecurity, and graduate study.

## My Attitude Toward Weakness

Being weak in a subject does not mean I should avoid it. When I have suitable prerequisites, clear guidance, and the opportunity to build something myself, I am willing to enter unfamiliar areas until they become understandable.
